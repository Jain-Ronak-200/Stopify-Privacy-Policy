02 DATA COLLECTION AND LOCAL PROCESSING

The Application is designed with a privacy-first architecture.

  • Personal Information: The Application requests your display name solely for the purpose of personalized in-app greetings. We do not collect, request, or store your email address, phone number, physical address, or any other personally identifiable information (PII).

03 REQUIRED PERMISSIONS AND API USAGE

To function as intended, the Application requires specific device permissions. We strictly adhere to Google Play Developer Policies regarding the use of these permissions:

UsageStats API

The Application requires the "Usage Access" permission to retrieve data regarding the time you spend on various applications. This data is used exclusively on your device to calculate your screen time and populate your activity dashboard. It is never transmitted off your device.

Unrestricted Battery Usage

To accurately monitor screen time continuously in the background, the Application requires exemption from battery optimization.

Notifications

The Application requires notification permissions to alert you when you are approaching or have reached your screen time limits.

Display Over Other Apps

The Application requires the "System Alert Window" permission to display a blocking interface or warning overlay on top of other applications. This is a mechanical necessity to enforce your self-imposed screen time limits. This permission is not used to monitor or collect data from other apps.

Accessibility Services

Stopify uses Android Accessibility Service only when the user enables the optional Short-Form Content Blocking feature. The service is used exclusively to identify short-form content interfaces (such as Reels, Shorts, and similar feeds) inside supported applications so that the app can block distracting content according to the user's settings. Accessibility data is processed entirely on the user's device. Stopify does not collect, store, transmit, or share accessibility events or personal information obtained through Accessibility Services.

Notification Listener

The Application requires Notification Listener Permission only for its notification-blocking optional feature. When a user selects specific apps, Stopify can block or hide their notifications to help reduce distractions. The Application does not read, store, share, or transmit the content of notifications or any personal data. Stopify is designed to function fully offline, and this feature does not require an internet connection.
